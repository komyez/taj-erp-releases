- ⬇️ آخر إصدار: صفحة [Releases](../../releases/latest)

## التحقق من الملف
قارن بصمة SHA-256 للملف الذي حمّلته بالبصمة المنشورة في الموقع وفي صفحة الإصدار:

```powershell
Get-FileHash .\TAJ-1.0.0.exe -Algorithm SHA256
```
